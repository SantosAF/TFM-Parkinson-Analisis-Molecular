## Description

This repository contains the main R script for the bioinformatics analysis of the Master's Thesis, focused on stratification and prediction in Parkinson's disease using the GSE99039 dataset.

---

## Complete Files and Reproducibility

To ensure full reproducibility and provide access to all required files (script, pre-computed data, and all generated figures and tables), a public Google Drive folder has been created.

**Click the following link to access all project materials:**

https://drive.google.com/drive/folders/1Kq5Eq2wMYmAZWtA6EXZG3hvUjDOj1PuF?usp=sharing

### Drive Folder Contents:

* **`entorno_TFM_TODO.RData`**: The R workspace environment (1.57 GB) containing all pre-computed objects and results. Essential for reproducing visualizations without waiting hours for computation.
* **`ML_Plots`**: A folder containing all plots, tables, and results generated by the script.

### Usage Instructions:

1. **Access** the Google Drive folder via the link.
2. **Download** both files.
3. **Unzip** the `ML_Plots.zip` file.
4. **Run:** Place `script_TFM.R` (located in this GitHub repository) and `entorno_TFM_TODO.RData` in the same root folder and open the script in RStudio to explore the results.

***Note**: Remember to set your working directory to the directory where the provided script and workspace environment are stored.
